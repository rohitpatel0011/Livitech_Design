## 1. Global AI Art Direction & Prompt Formula

To ensure all images across the website look like a cohesive, multi-crore architectural portfolio rather than random stock photos, use this exact prompt formula for Midjourney v6, DALL-E 3, or Google Imagen 3:

```
[Subject & Architectural Scope] + [Materials & Brand Color Details] + [Lighting & Environment] + [Camera, Lens & Technical Settings] + [Style & Mood Flags]
```

### Universal Style Keywords to Include in Prompts:
* **Style:** `Architectural digest photography, photorealistic, 8k resolution, ultra-detailed architectural render, award-winning contemporary architecture`
* **Camera & Lens:** `Shot on Hasselblad H6D-100c, 35mm tilt-shift lens, f/8 aperture, razor-sharp architectural lines, zero barrel distortion`
* **Lighting:** `Golden hour warm sunlight with subtle blue hour shadows, volumetric atmospheric lighting, cinematic natural illumination`
* **Color Harmony:** `Warm copper accents (#DA5F36), reflective silver-blue tinted glass (#8699C1), deep obsidian navy shadows (#0D0F1B)`
* **Negative Prompt (Things to Avoid):** `cartoon, 3d render look, plastic materials, blurry, oversaturated colors, distorted columns, impossible structural physics, generic western suburban houses, messy construction debris`

### Pro Tip for Generation:
1. Always generate in **WebP** or convert PNG/JPG to WebP at 85% quality using tools like Squoosh or TinyPNG before placing in `public/images/`.
2. For Hero Slides, generate with `--ar 16:10` to fit the exact desktop card frame without cropping.
3. For Blueprint PIP thumbnails, generate with `--ar 1:1`.

## 9. Production Execution & Performance Checklist

### 1. Seed Consistency for Blueprint vs Reality Slider:
* Midjourney me Image B (Reality photo) banate waqt Image A ka direct CAD wireframe as an image prompt (`--sref` ya directly initial image link) pass karein aur parameter me `--cw 20` ya `--cref` use karein taaki roof pitch, column positions aur camera angle exact match karein.

### 2. Next.js `<Image/>` Optimization:
* Hero active slide par `priority` prop set karein taaki Largest Contentful Paint (LCP) < 1.2s rahe:
```tsx
<Image 
  src="/images/hero/hero-stage-1-architecture.webp" 
  alt="Livitech Design Architectural Duplex 3D Elevation" 
  width={1920} 
  height={1200} 
  priority 
  className="object-cover w-full h-full"
/>
```

### 3. Automated Sharp Batch Conversion Script:
* Agar raw generation PNGs folder me aati hain, to ek one-line node script se sabhi images ko target dimensions aur WebP compression me batch export kar sakte hain:
```bash
npx sharp-cli -i ./raw/*.png -o ./public/images/hero/ -f webp -q 85
```
